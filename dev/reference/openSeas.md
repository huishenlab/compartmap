# Human and mouse open sea CpGs as GRanges objects

These objects were generated using the
BSgenome.Hsapiens.UCSC.hg19/BSgenome.Hsapiens.UCSC.hg38 and Mus.musculus
packages.

## Usage

``` r
data(openSeas.hg38, package = "compartmap")

openSeas.hg38

openSeas.hg19

openSeas.mm9

openSeas.mm10
```

## Format

An object of class `GRanges` of length 60378.

An object of class `GRanges` of length 33708.

An object of class `GRanges` of length 13225.

An object of class `GRanges` of length 13208.
